# Smart Employee Management System

A backend REST API application developed using Spring Boot and MySQL to manage employee records efficiently. The project supports CRUD operations, employee search/filtering, validation, exception handling, and interactive API documentation using Swagger.

---

## 🚀 Features

- Add new employees
- View all employees
- Get employee by ID
- Update employee details
- Delete employee records
- Search employees by name
- Filter employees by role
- Filter employees based on salary
- Input validation using Jakarta Validation
- Global exception handling
- Swagger/OpenAPI documentation
- MySQL database integration using JPA/Hibernate

---

## 🛠️ Tech Stack

- Java 17
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Swagger/OpenAPI
- Postman
